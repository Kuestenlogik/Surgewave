== Readiness ==

  A broker is ready only once it has caught up with the metadata log, which takes a majority
  of the brokers. A fresh install takes about half a minute:

    kubectl rollout status statefulset/{{ $fullname }} -n {{ .Release.Namespace }}

== Number of brokers ==

  broker.replicaCount is part of every broker's configuration (cluster nodes, quorum voters).
  Changing it restarts all brokers with a new quorum; kubectl scale alone does not add a
  broker to the cluster.
