# Surgewave logos

Every file here is generated by `scripts/branding/generate-logos.mjs` from one drawing,
`scripts/branding/surgewave_mark_source.svg`, configured in `scripts/branding/brand.json` (see `scripts/branding/README.md`; the
generator is shared with Terracle and kept identical); do not edit them by hand, the next run replaces them and deletes
anything it did not write. PNGs come at 1x and @2x with a transparent background. Use `adaptive` where a page switches
between light and dark, `colored` on light, `white` on dark or on photos, `black` for single-colour print.

## Mark

| File | Use |
|---|---|
| `surgewave_mark_colored.svg`, `.png`, `@2x.png` | The mark in its colours (512 / 1024 px), on light backgrounds. |
| `surgewave_mark_black.svg`, `.png`, `@2x.png` | Single colour black, for print and light backgrounds. |
| `surgewave_mark_white.svg`, `.png`, `@2x.png` | Single colour white, for dark backgrounds. |
| `surgewave_mark_adaptive.svg` | Follows the theme: colours on light, the navy turns white on dark. |
