# Surgewave logos

Every file here is generated by the shared branding tool (`scripts/branding/tool/generate-logos.mjs`, a pinned copy
of `tools/branding` in the Kuestenlogik repository; see `scripts/branding/tool/README.md`) from one drawing,
`scripts/branding/surgewave_mark_source.svg`, configured in `scripts/branding/brand.json` (both pinned copies of
`brand/products/surgewave` in the Kuestenlogik repository, edited only there and vendored with the tool); do not edit them by hand, the
next run replaces them and deletes anything it did not write, and `generate-logos.mjs --check` fails when they differ
from the drawing. PNGs come at 1x and @2x with a transparent background, each also as a lossless WebP (`.webp`). Use
`adaptive` where a page switches between light and dark, `colored` on light, `white` on dark or on photos, `black` for
single-colour print.
