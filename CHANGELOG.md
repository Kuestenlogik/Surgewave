# Changelog

Release notes live on **GitHub Releases**:
<https://github.com/Kuestenlogik/Surgewave/releases>

Each tag (`v0.x.y` and the matching `-rc.N` pre-releases) carries a release page: the curated
notes from [`docs/release-notes/`](docs/release-notes/) — highlights, fixes, breaking changes
and how to migrate — followed by the commits since the previous tag, grouped by kind. That page
is the single source of truth; this file is a pointer, so the notes are kept in one place only.

What the next release will contain is written up in
[`docs/release-notes/upcoming.md`](docs/release-notes/upcoming.md) as the work lands on `main`.
[`RELEASE_NOTES.md`](RELEASE_NOTES.md) mirrors the published releases for offline reading.
The entries this file held for v0.1.x to v0.3.x are kept in
[`docs/release-notes/history-before-0.4.md`](docs/release-notes/history-before-0.4.md).

To see the notes for the version you have installed:

    open https://github.com/Kuestenlogik/Surgewave/releases/tag/v<that-version>
